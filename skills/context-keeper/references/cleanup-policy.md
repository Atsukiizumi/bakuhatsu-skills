# 上下文与文件清理策略

默认 `cleanup` 仅盘点、分类与给出预览。它不是系统垃圾清理器。

| 类别 | 默认动作 | 是否需单独确认 |
|---|---|---|
| 活跃摘要中的重复内容 | 在新摘要里去重、保留权威引用 | 无需删除源文件 |
| docs 与代码冲突 | 核实并标记，给出最小 diff | 覆盖历史文档需授权 |
| 失效 ADR/旧计划 | 标为 superseded，链接新决策 | 文件移动/删除需确认 |
| 大型工具输出 | 从新摘要移除，留路径或归档指针 | 删除原始输出需确认 |
| 未提交/未跟踪文件 | 保护并在 HANDOFF 记录 | 不得自动清理 |
| .git、数据库、密钥及生产日志 | 绝不作为一般清理候选 | 不提供破坏性默认动作 |
| 宿主聊天历史/隐藏记忆 | 仅说明宿主能力，不伪造操作 | 必须通过平台的授权流程 |

审批前需要告知候选对象、为何冗余、引用位置、丢失后影响、备份/回滚方案。禁止默认执行 `git clean`、`git reset --hard`、`rm -rf`、强制推送、删除数据库。
