# 可复制到有效项目指令文件的简短规则（按平台选择一份）

> 这不是新建三份互相重复的 AGENTS.md、CLAUDE.md、GEMINI.md 的建议。请选择当前平台已使用的**单一现役文件**，只追加以下精简规则：

```markdown
## Context Keeper 工作状态维护

- 在重大决策达成、开发/测试阶段交付、任务切换或即将压缩上下文时，
  主动使用 `context-keeper` 的 maintain/compact 流程维护 `.ai-context/ACTIVE.md` 和 `HANDOFF.md`。
- 先保留用户限制、未提交修改、测试状态、错误根因和可执行下一步，再请求宿主原生压缩。
- 无真实 token 指标时不得猜测窗口占用率；无原生压缩能力时不得声称已压缩模型内部会话。
- 摘要只作为索引，恢复后必须先核对代码、Git 和测试；不自动删除或重置任何文件。
```

使用平台提供的引用/导入机制避免重复维护；不要覆盖旧项目规则。
